# Heaven Discord Bot

Discord bot project owned by `fengie`. This public repository contains product-specific code and configuration only.

## Heaven Toolbox relationship

`fengie/heaven-toolbox` is the private parent for reusable engineering capabilities, policy references, and reviewed lessons. This repository must never publish private Toolbox source, credentials, or host configuration.

The bootstrap is tracked as an initial adoption trial. A pinned, non-authorizing agent entry and app specification are added in a reviewed bootstrap change. Source integration does not imply the bot is deployed.
